# Prompt templates

Copy a template and replace every `<placeholder>`.

## Basic note

```
Use problem-first-teaching-notes to write a teaching note on <concept>.
My students are <level, e.g. second-year undergraduates> and already know <prerequisites>.
```

## Note anchored in a specific application

```
Write a problem-first teaching note on <concept> for <audience>.
Use <application or setting, e.g. road networks, clinical trials, image compression> as the running example.
```

## Note with a required format

```
Teach <concept> to <audience> as a problem-first note. Deliver it as <Markdown / LaTeX / Word>.
Keep it to about <length, e.g. 4 pages> and include check-your-understanding questions.
```

## Rewrite an existing definition-first note

```
Here is my current lecture note on <concept>: <paste or attach>.
Rewrite it with problem-first-teaching-notes: same content and level, but start from the problem and let the definition appear later.
```

## Follow-ups

```
Make section <n> more intuitive; my students struggle with <step>.
Replace the running example with <new setting> and recompute the worked numbers.
Add a short section contrasting <concept> with <related concept>.
```

## Chinese example (中文示例)

```
用 problem-first-teaching-notes 给 <学生背景> 写一份关于 <概念> 的讲义，用中文。
```
